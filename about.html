ABOUT THIS PROJECT / 00

讓知識可以持續
被整理、被連結。

傳播觀察誌是一個開放式學習筆記計畫，嘗試把傳播學的理論語言，轉化為能夠理解媒體、平台與社會現象的分析工具。

01 / PURPOSE

為什麼建立？

面對快速變動的媒體環境，單純記住理論定義並不足夠。本網站透過「概念—機制—案例—反思」的整理方式，讓知識能被複習，也能被拿來分析新的現象。

02 / METHOD

如何整理內容？

理論條目盡量回到代表學者與原始文獻；案例條目需交代時間、資料來源與涉及單位；作者分析則與可查證事實分開呈現。每篇文章都附上延伸參考資料。

03 / SYSTEM

如何持續擴充？

網站使用共用文章模板，內容集中管理於 data/articles.js。新增文章不必複製網頁版型；只需依照 AGENTS.md 的欄位與內容規範新增一筆資料。

EDITORIAL PRINCIPLES
